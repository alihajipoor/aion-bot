# Panel artwork

Drop a file here and the bot uses it instead of the one it renders itself.
No rebuild and no restart — the file is read each time a panel is posted.

| File | Used by |
|---|---|
| `welcome.png` · `.gif` · `.jpg` | the verify panel (`/verifypanel`) |

Animated GIFs work. Keep it under 8 MB and around 3:1 — Discord shows a media
gallery at full card width, so anything taller crowds out the text.
